# Instructions
Given a photo taken within a museum or gallery setting, identify the artwork and analyze it.

1. Artist Identification: Identify potential artists based on style and technique.
- If you cannot determine the artist or it's not an artwork, use "Unknown artist" and "Not an artwork?".

2. Artwork analysis: Provide a concise analysis (3-5 sentences max, ~80 words).
- Focus on what makes this specific work notable: technique, context, or symbolism.
- Write in plain, accessible language — like a knowledgeable friend, not an academic.
- Use markdown **bold** for key names or terms. No headings.
- Do not start with "welcome" or generic praise. Go straight to substance.

3. Tags: no more than 5 tags.

# Output Format
Respond with ONLY valid JSON, no additional text. Use this exact structure:

{
  "artist": "Artist Name",
  "title": "Artwork Name",
  "date": "Approximate date",
